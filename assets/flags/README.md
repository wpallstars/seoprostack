# Flags

3:2 country flags from [country-flag-icons](https://gitlab.com/catamphetamine/country-flag-icons) 1.6.20 (MIT, `LICENSE` in this folder), unchanged. The language switcher (`includes/features/class-seoprostack-language-switcher.php`) shows the flag of a language's country; a country not here falls back to TranslatePress's own flag for the locale. Add a country by copying its `3x2/XX.svg` here.
