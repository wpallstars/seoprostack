One free plugin for faster, tidier WordPress: the jobs of 40+ plugins, each with a switch.

== Description ==

Faster admin, easier publishing and safer logins.

Free and open source. Details: the plugin's Read Me tab.

Safe features start on; others stay off. **Settings → SEO Pro Stack** has **Search features**. Replacements import once without changing originals, and wait while the old plugin is active.

= A calmer, faster admin =

* **Light, Dark or System**: per-person wp-admin colour mode, from the admin bar or settings header (network settings too). Dark reaches every plugin's and theme's screens: dark copies of their stylesheets, kept in uploads/seoprostack-dark and deleted on deactivation.
* **Developer admins**: choose who manages plugins, themes, admins and site addresses.
* **Organise the admin menu**: sections, role previews and contributor menus.
* **Tidy the dashboard**, **Dashboard and sidebar widgets**, **Hide admin notices** and **More menu**.
* **Quiet Freemius prompts**, **Quiet Appsero prompts** and **Quiet Imagify suggestions**: fewer nags.
* **Dev tab in the block editor**: developer-only plugin panels.
* **Tidy admin screens**, **Tidy WooCommerce admin**, **Tidy the login screen**, **Simpler block editor**, **Remove WordPress extras**, **Fewer Heartbeat requests**, **Limit post revisions** and **Lighter WooCommerce pages**.
* **No fade between admin screens**, **Correct update counts**, **Readable list columns** and **Notification emails**.

= Safer logins and access =

* **Magic login links**: one-time email links, safe from link scanners.
* **Admin bar and dashboard access**: restrict by role; admins keep access.
* **Turn off unused remote access**: XML-RPC, application passwords and exposed files.
* **Minimum password length**: 12 characters for new passwords, on by default.
* **Known vulnerabilities**: shows what the free WPVulnerability plugin finds.
* **Maintenance mode**: a 503 page with revocable 24-hour bypass links.

= Writing and publishing =

* **Publishing queue**: undated posts take the next free slot.
* **Duplicate posts**, **Staged new versions** and **Shareable preview links**.
* **Pinned posts for any post type**, **Select all across pages**, **Order by hand**, **Change post type**, **Term tools**, **Search custom fields** and **Old post addresses**.
* **Tag clouds and related posts**: keeps TaxoPress and Tag Groups pages working.
* **Custom fields to content**: ACF/SCF text to content and excerpts.
* **Restrict content** by membership or role. **Menu item visibility** by login or role.
* **iFrame block**, **Link cards**, **Wikipedia previews**, **Word documents**, **Brand icons** and **Like, save and share**.
* **Spectra block replacements**, **TranslatePress colours** and **Kadence query filters**.
* **WP Grid Builder colours**: cards and facet inputs follow Kadence dark mode; light mode stays unchanged.
* **Kadence colour check**: Site Health finds Customizer colours hard to read in light or dark mode and moves them to the palette, with Restore.

= Media =

* **Copy linked images to Media Library** on save, and **Paste into the Media Library**.
* **WebP and AVIF images**: smaller files at the same address.
* **Media in cloud storage** (off): S3-compatible picture delivery; local files stay.
* **Resize large uploads**, **Replace media files** and **Watermark pictures**, keeping originals.
* **SVG uploads**: cleaned, chosen roles only. **Dark mode image contrast** for logos.
* **Website screenshots**: block and `[browser-shot]` shortcode.
* **Avatars without Gravatar**: served locally. Profile pictures: JPEG, PNG, GIF or WebP up to 5 MB (or the site's lower limit), 25 megapixels and 8,000 pixels on either side.

= Links and speed =

* **Rank Math defaults**: keywords from titles and pillar warnings.
* **Short links** with click counts and **410 Gone** for removed pages.
* **Short addresses for custom post types**.
* **External link icons**: script-free, replacing Link Whisper's icon only.
* **Internal linking tools** (off): suggestions, undo and Link Whisper checks.
* **Recommended speed settings**, **Load pages before the click**, **Delay scripts until interaction**, **Delayed Google Analytics** and faster Kadence Blocks editing.
* **Ask before licence checks**. **Calls to other sites** (off): monitor, limit or block.
* **Clean the database weekly**: spam, bin, expired data and gone plugins' tasks.
* **Count terms and comments in the background** and **Remember admin counts** (off).
* **Load large settings only where they are used** (single sites).
* **Faster page counts on long lists** (off): exact page numbers.
* **Database key cleanup** with restore SQL. **Add database keys** (off): faster lookups.
* **Database character set**: opt-in utf8mb4 conversion for emoji.
* **Load plugins only where needed**: skips unused plugins; learns from anonymous, cookie-free public GET requests.

* **Google Analytics** (www.googletagmanager.com): when enabled with a measurement ID, browsers load gtag.js and send Google page views under its privacy policy. Logged-in users are excluded.
* **Screenshot services**: when enabled, your server sends page addresses to make screenshots; visitors do not contact them.
* **Thum.io** (image.thum.io), the default: see [Thum.io](https://www.thum.io/).
* **Microlink** (api.microlink.io, or pro.microlink.io with a key): [terms](https://microlink.io/tos), [privacy policy](https://microlink.io/privacy).
* **ApiFlash** (api.apiflash.com): [terms](https://apiflash.com/terms_of_service), [privacy policy](https://apiflash.com/privacy_policy).

== Installation ==

Install from Plugins → Add New and activate. Set features in Settings → SEO Pro Stack.

== Frequently Asked Questions ==

= What happens if I deactivate or delete the plugin? =

Deactivation restores local image addresses, removes the must-use file and tries to remove marked `.htaccess` rules. Deletion removes settings, caches, profile pictures, WebP/AVIF copies, storage records and short links; imported media, watermarked originals and bucket objects stay.

= Does it work on multisite? =

Yes. **Network Admin → Settings → SEO Pro Stack** sets new sites' settings and can apply each card to every site. Super admins are developers on every site.

= Is the magic login safe? =

Random, hashed links work once for an hour. Password-step two-factor checks are skipped: then choose “Everyone except administrators”.

= Where do updates come from? =

From where you installed it. GitHub gets new versions first; WordPress.org 30 days on, security fixes at once.

= Where do I get help? =

Use **Support** in Settings → SEO Pro Stack or [GitHub](https://github.com/wpallstars/seoprostack/issues).
